Bug Tracker — веб-приложение для управления багами, версиями и релизами программных продуктов. 
Реализована ролевая модель доступа (администратор, разработчик, менеджер, тестировщик). Пользователи могут создавать, редактировать и удалять баги, управлять версиями приложений и релизами.

Основные возможности
1. Аутентификация по email и паролю (без двухфакторной авторизации).
2. Роли и права: администратор управляет пользователями и всеми сущностями; разработчик и тестировщик работают с багами; менеджер управляет версиями.
3. CRUD для багов, версий, релизов, пользователей (админ).
4/ Веб-интерфейс на HTML + CSS.

Технологический стек
1. Java 21, Spring Boot 3.4.4, Spring Security, Spring Data JPA, Thymeleaf.
2. PostgreSQL, Liquibase, Lombok.
3. Gradle как система сборки.
